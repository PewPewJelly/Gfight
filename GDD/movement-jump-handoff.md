# 이동 및 점프 구현 핸드오프

## 범위와 근거

첨부 메모의 **「이동 및 점프」** 항목만 반영한다. 아래의 확정 사항 외에는 구현 규칙이나 수치를 임의로 정하지 않는다.

## 확정된 요구사항

| 입력/상황 | 요구 동작 |
|---|---|
| `A` | 플레이어가 왼쪽으로 이동한다. |
| `D` | 플레이어가 오른쪽으로 이동한다. |
| `W` | 점프한다. |
| `S` | 플랫폼 아래로 이동한다. |
| 땅에 닿음 | 점프 기회를 2회 얻는다. |
| 점프 1회 실행 | 점프 기회 1회를 소모한다. |
| 넉백 중 | 이동과 점프를 할 수 없다. |

## 구현에 필요한 상태와 처리 규칙

- 플레이어의 **남은 점프 기회**를 관리한다. 값은 `0`, `1`, `2` 중 하나다.
- 플레이어가 땅에 닿으면 남은 점프 기회를 `2`로 설정한다. 점프가 실제로 실행될 때에만 `1` 감소시킨다.
- 남은 점프 기회가 `0`이면 `W` 입력으로 점프를 실행하지 않는다.
- 넉백 상태에서는 `A`·`D`에 의한 이동과 `W`에 의한 점프를 실행하지 않는다. 이때 점프 기회도 소모하지 않는다.
- `S` 입력에 대한 플랫폼 아래 이동 기능을 제공한다. 해당 동작의 정확한 조건과 충돌 처리 방식은 아래 미정 사항이 정해져야 완성할 수 있다.

## 확인 기준

1. 땅에 닿은 뒤 남은 점프 기회가 `2`가 된다.
2. 점프를 한 번 실행하면 `1`, 두 번 실행하면 `0`이 된다. 기회가 `0`일 때 추가 점프는 실행되지 않는다.
3. 점프 기회가 `0`인 상태에서 땅에 닿으면 다시 `2`가 된다.
4. 넉백 중 `A`·`D`·`W` 입력은 각각 이동·점프를 실행하지 않는다. 차단된 `W` 입력은 점프 기회를 소모하지 않는다.
5. 넉백 상태가 아닐 때 `A`와 `D`는 각각 왼쪽·오른쪽 이동에 연결된다.
6. `S`는 플랫폼 아래 이동에 연결된다. 완료 판정은 아래 플랫폼 관련 미정 사항이 결정된 후 구체화한다.

## 미정 사항 — 구현 전에 결정 필요

| 항목 | 확인할 내용 |
|---|---|
| 이동/점프 수치 | 이동 속도, 가속·감속, 점프 높이·힘, 중력 등 구체 수치 |
| 공중 이동 | 점프하거나 낙하하는 동안 `A`·`D` 이동이 가능한지, 가능하다면 지상과 같은 방식인지 |
| 점프 입력 | `W`를 누른 순간마다 점프하는지, 누르고 있는 동안 재입력을 허용하는지, 입력 버퍼·코요테 타임을 적용하는지 |
| 땅 판정 | 무엇을 ‘땅에 닿음’으로 볼지. 플랫폼 위 착지도 점프 기회를 회복하는지 |
| 플랫폼 아래 이동 | 어떤 플랫폼에서 가능한지, `S` 단독 입력인지, 통과 중 충돌을 어떻게 처리하는지, 일반 바닥에서도 동작하는지 |
| 넉백 | 시작·종료 조건과 지속시간, 넉백 중 `S` 동작 가능 여부, 넉백 자체의 이동은 허용되는지 |
| 동시 입력 | `A`와 `D`를 동시에 누를 때의 처리 |

위 미정 사항에는 임시 기본값을 넣지 않는다. 특히 플랫폼 통과와 넉백 세부 동작은 담당자의 결정이 있어야 구현 및 검증 범위를 확정할 수 있다.
