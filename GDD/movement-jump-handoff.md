# 이동 및 점프 구현 핸드오프

## 범위

플레이어 이동·점프 입력과 점프 기회, 넉백 중 입력 제한을 정의한다. 구체적인 수치와 플랫폼 통과 조건은 임의로 정하지 않는다.

## 확정 규칙

| 항목 | 규칙 |
|---|---|
| `A` | 플레이어가 왼쪽으로 이동한다. |
| `D` | 플레이어가 오른쪽으로 이동한다. |
| `W` | 점프한다. |
| `S` | 플랫폼 아래로 이동한다. |
| 땅 접촉 | 점프 기회를 2회 얻는다. |
| 점프 실행 | 점프 기회를 1회 소모한다. |
| 넉백 중 | `A`·`D` 이동과 `W` 점프를 실행할 수 없다. 차단된 점프는 기회를 소모하지 않는다. |

## 처리 흐름

1. 플레이어의 남은 점프 기회를 `0`, `1`, `2` 중 하나로 관리한다.
2. 땅에 닿으면 남은 점프 기회를 `2`로 설정한다. 플랫폼 위 착지를 땅 접촉으로 볼지는 [검토]에서 결정한다.
3. 남은 기회가 있을 때 점프가 실제로 실행되면 기회를 `1` 줄인다. 기회가 `0`이면 `W`로 점프하지 않는다.
4. 넉백 중에는 `A`·`D` 이동과 `W` 점프를 실행하지 않는다.
5. `S`를 플랫폼 아래 이동에 연결한다. 작동 조건과 충돌 처리 방식은 [검토]에서 결정한다.

## 확인 기준

- 땅에 닿으면 남은 점프 기회가 `2`가 된다.
- 점프를 한 번 실행하면 `1`, 두 번 실행하면 `0`이 되고, `0`일 때 추가 점프는 실행되지 않는다.
- 점프 기회가 `0`인 상태에서 땅에 닿으면 다시 `2`가 된다.
- 넉백 중 `A`·`D`·`W` 입력은 각각 이동·점프를 실행하지 않으며, 차단된 `W`는 기회를 소모하지 않는다.
- 넉백 중이 아닐 때 `A`와 `D`는 각각 왼쪽·오른쪽 이동에 연결된다.
- `S`는 플랫폼 아래 이동에 연결한다. 세부 완료 기준은 통과 조건이 확정된 뒤 정한다.

## [검토]

- 이동 속도, 가속·감속, 점프 높이·힘, 중력 등 구체 수치는 ??다.
- 공중에서 `A`·`D` 이동이 가능한지, 가능하다면 지상과 같은 방식인지는 미정이다.
- `W`를 누른 순간마다 점프하는지, 누르고 있는 동안 재입력을 허용하는지, 입력 버퍼·코요테 타임 적용 여부는 미정이다.
- 무엇을 ‘땅에 닿음’으로 볼지와 플랫폼 위 착지가 점프 기회를 회복하는지는 미정이다.
- `S` 아래 이동이 가능한 플랫폼의 종류, 단독 입력 여부, 통과 중 충돌 처리, 일반 바닥에서의 동작은 미정이다.
- 넉백의 시작·종료 조건과 지속시간은 ??이며, 넉백 중 `S` 동작과 넉백 자체의 이동 허용 범위는 미정이다.
- `A`와 `D`를 동시에 누를 때의 처리는 미정이다.
