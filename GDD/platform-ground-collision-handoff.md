# 플랫폼·땅 판정 구현 핸드오프

## 범위

첨부 메모의 플랫폼 관련 요구사항을 기록한다. **이번 구현 범위는 플레이어와 땅이 충돌할 수 있는 조건을 만들고, 플레이어 아래의 `GroundChecker`로 땅 접촉 여부를 판정하는 것**이다. 충돌에 따른 이동·점프 처리나 플랫폼 통과 동작까지 새로 정의하지 않는다.

## 메모에 명시된 요구사항

| 항목 | 요구사항 | 이번 범위 |
|---|---|---|
| 플레이어와 플랫폼 | 플레이어가 플랫폼 위에 서 있을 수 있어야 한다. | 플레이어와 땅/플랫폼의 충돌 조건 및 땅 판정 준비 |
| 플레이어끼리 겹침 | 플레이어끼리는 겹치면 안 된다. | 요구사항으로 기록. 플레이어 간 충돌 구현은 이번 범위 밖 |
| 플랫폼 크기 | 최소 2명이 겹치지 않고 설 수 있으며, 너무 좁지 않은 정도의 크기 | 요구사항으로 기록. 구체 크기와 배치는 미정 |

## 이번 구현 요구사항

1. 플레이어와 땅/플랫폼을 충돌 대상으로 구분할 수 있게 구성한다. 사용 엔진의 레이어·마스크·태그 등 구체 수단은 프로젝트 구조에 맞춘다.
2. 플레이어와 땅/플랫폼 사이에 **충돌이 허용되는 조건**을 설정한다. 서로 접촉했을 때 플레이어가 땅을 통과하지 않고 그 위에 있을 수 있어야 한다.
3. 플레이어의 아래쪽에 `GroundChecker`를 둔다. `GroundChecker`는 땅 접촉 여부를 판정하는 용도로 사용하며, 플레이어 본체의 충돌 판정과 역할을 구분한다.
4. `GroundChecker`가 땅 접촉 상태를 외부에서 사용할 수 있게 제공한다. 이전 이동·점프 핸드오프의 ‘땅에 닿으면 점프 기회 2회’ 규칙이 이 판정 결과를 사용할 수 있어야 한다.
5. `GroundChecker`의 판정 대상과 플레이어가 실제로 충돌하는 대상의 범위를 일치시킨다. 플랫폼을 땅 판정에 포함할지는 아래 미정 사항을 확인한 뒤 확정한다.

## 확인 기준

- 플레이어가 땅 위에 있을 때 플레이어와 땅 사이의 충돌이 성립하며, `GroundChecker`가 땅 접촉 상태를 제공한다.
- 플레이어가 땅과 떨어져 있을 때 `GroundChecker`는 땅 접촉 상태를 제공하지 않는다.
- 점프 로직이 사용할 수 있도록 땅 접촉 상태를 참조할 수 있다.
- 플레이어 간 겹침 방지와 플랫폼 너비는 이번 구현 완료 판정에 포함하지 않는다.

## 미정 사항 — 확정이 필요한 내용

| 항목 | 확인할 내용 |
|---|---|
| 땅의 범위 | 일반 바닥과 플랫폼을 모두 땅으로 취급할지, 별도 종류로 구분할지 |
| 플랫폼 충돌 방식 | 모든 방향에서 충돌하는지, 위에서만 서고 아래로 통과할 수 있는 플랫폼인지. 앞선 `S` 아래 이동 요구사항과 함께 결정 필요 |
| GroundChecker 판정 | 검사 범위·위치·접촉 판정 기준과, 플랫폼 모서리에서의 처리 |
| 플레이어 간 겹침 방지 | 이후 작업에서 충돌체로 막을지, 다른 방식으로 위치를 분리할지 |
| 플랫폼 크기 | ‘최소 2명’, ‘너무 좁지 않음’을 만족하는 실제 너비와 플레이어 크기 기준 |

구체 충돌체 크기, 검사 거리, 플랫폼 너비 등의 수치는 임의로 정하지 않는다.
