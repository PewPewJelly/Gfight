# 플랫폼·땅 판정 구현 핸드오프

## 범위

플레이어와 땅/플랫폼의 충돌 조건을 만들고, 플레이어 아래 `GroundChecker`로 땅 접촉 여부를 판정한다. 이동·점프 처리와 플랫폼 통과 동작의 세부 구현은 이 문서의 범위 밖이다.

## 확정 규칙

| 항목 | 규칙 |
|---|---|
| 플레이어와 플랫폼 | 플레이어가 플랫폼 위에 서 있을 수 있어야 한다. |
| 플레이어 간 겹침 | 플레이어끼리는 겹치면 안 된다. 구체적인 방지 방식은 미정이다. |
| 플랫폼 크기 | 최소 2명이 겹치지 않고 설 수 있으며 너무 좁지 않아야 한다. 실제 너비는 ??다. |
| 시작 위치 | 플레이어들은 서로 다른 플랫폼 위 위치에서 시작한다. |
| 재스폰 위치 | 스톡이 남은 플레이어는 플랫폼에 닿아 있는 랜덤한 위치에서 재스폰한다. |
| 땅 접촉과 점프 | 땅에 닿으면 점프 기회를 2회 얻는다. 플랫폼 착지를 땅 접촉에 포함할지는 미정이다. |

## 처리 흐름

1. 플레이어와 땅/플랫폼을 충돌 대상으로 구분한다. 엔진의 레이어·마스크·태그 등 구체 수단은 프로젝트 구조에 맞춘다.
2. 접촉 시 플레이어가 땅을 통과하지 않고 그 위에 있을 수 있도록 충돌을 허용한다. `S`를 통한 통과가 가능한 플랫폼의 충돌 방식은 [검토]에서 결정한다.
3. 플레이어 아래에 `GroundChecker`를 두고, 본체의 충돌 판정과 역할을 구분한다.
4. `GroundChecker`의 땅 접촉 상태를 이동·점프 로직이 참조할 수 있게 제공한다.
5. `GroundChecker`의 판정 대상과 플레이어가 실제로 충돌하는 대상의 범위를 일치시킨다. 플랫폼을 땅 판정에 포함할지는 [검토]에서 결정한다.

## 확인 기준

- 플레이어가 땅 위에 있을 때 충돌이 성립하고 `GroundChecker`가 땅 접촉 상태를 제공한다.
- 플레이어가 땅과 떨어져 있을 때 `GroundChecker`는 땅 접촉 상태를 제공하지 않는다.
- 점프 로직이 땅 접촉 상태를 참조할 수 있다.
- 플레이어 간 겹침 방지와 플랫폼 너비는 이 문서의 구현 완료 판정에 포함하지 않는다.
