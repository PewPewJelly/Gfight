# 캐릭터 기획서 양식

> 새 캐릭터를 만들 때 이 파일을 복사해 `GDD/characters/<id>.md`로 저장하고 채운다. 작성 예시는 [`test_fighter.md`](test_fighter.md).
>
> - 표기: 아직 정하지 않은 값은 `??`, 논의가 필요한 항목은 `[검토]`, 기획이 제안하는 기본값은 `[제안]`(Docs/00 §2.1-6). 개발은 `??`·`[검토]`를 확정하지 않고 임시값으로 구현한 뒤 `GDD/implementation-status.md`에 적는다.
> - 단위: 거리·크기 px, 속도 px/s, 가속도 px/s², 시간 초, 배율 %. 방향은 Godot 좌표(오른쪽 +x, **아래 +y**).
> - "기본값" 열은 테스트 파이터(현재 유일한 캐릭터)의 값이다. 기본값과 같으면 "이 캐릭터" 칸에 `=`만 적는다.

### 반영 표시

각 표의 "반영" 열은 지금 코드에서 그 값이 캐릭터마다 따로 적용되는지를 뜻한다.

| 표시 | 뜻 |
|---|---|
| 적용 | 카탈로그 항목과 그림 파일만 추가하면 바로 반영된다 |
| 공통 | 지금은 모든 캐릭터가 한 값을 같이 쓴다(`resources/*.tres` 또는 코드 상수). 기본값과 다르게 적으면 개발 작업 "캐릭터별 조정값 연결"(12장)이 먼저 필요하다 |
| 신규 | 코드에 아직 없는 항목. 규칙 확정과 개발 작업이 필요하다 |

## 6. 공격 (`AttackData`)

공통 규칙 (`GDD/attack-handoff.md`, `GDD/implementation-status.md` §공격):

- 입력: 앞 = `J` 또는 `A`/`D`+`J`, 위 = `W`+`J`, 아래 = `S`+`J`. `W`·`S`를 같이 누르면 위 공격.
- 판정: 선딜레이 없이 공격 시작 프레임에 사각형 범위로 한 번 판정한다. 공격 1회당 상대마다 한 번만 맞는다.
- 발사 속도 = 기본 발사 속도 × (1 + 맞은 뒤 배율 ÷ 100). 예: 배율 0%인 상대가 배율 증가 12%인 공격에 맞으면 발사 속도 × 1.12.
- 피해는 기록용이다. HP나 피해에 따른 탈락은 없고, 날아가는 거리는 배율로만 정해진다.

각 공격 표의 항목 뜻:

| 항목 | 필드 | 뜻 |
|---|---|---|
| 피해 | `damage` | 누적 피해 기록 |
| 배율 증가 | `percent_increase` | 맞은 상대의 넉백 배율이 오르는 양 (%) |
| 기본 발사 속도 | `base_launch_speed` | 배율 0%일 때 상대가 날아가는 속도 |
| 피격 경직 | `hitstun_seconds` | 맞은 상대가 이동·점프·공격을 못 하는 시간 |
| 범위 길이 | `reach` | 몸 가장자리에서 공격 방향으로 뻗는 길이 |
| 범위 폭 | `width` | 공격 방향과 수직인 두께 |
| 발사 방향 | `launch_direction` | 오른쪽을 볼 때 기준 (x, y). 왼쪽을 보면 x가 뒤집힌다. 위로 띄우려면 y를 음수로 |

## 10. 확인 기준

- [ ] 대기방 캐릭터 탭에 표시 이름과 그림이 나온다.
- [ ] 이 캐릭터를 추가해 2종 이상이 되면 "랜덤" 칸이 생긴다.
- [ ] 선택한 캐릭터가 경기 설정(`MatchSetup.characters`)에 전달된다.
- [ ] "공통" 항목을 기본값과 다르게 정했다면, 경기에서 이 캐릭터에만 그 값이 적용된다.
- [ ] 공격 3종의 범위·배율 증가·발사 방향이 6장 표와 같다.
- [ ] headless 테스트(`tests/run_checks.ps1`)가 통과한다.
