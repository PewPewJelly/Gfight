# 캐릭터 작업실 사용 안내

코드를 몰라도 캐릭터를 만들고 수치와 사용감을 조절할 수 있는 도구다. Godot 4.7.2로 프로젝트를 열고 화면 위쪽의 **캐릭터 작업실** 탭을 누른다.

## 새 캐릭터 만들기

1. 왼쪽 아래 **새 캐릭터**를 누른다.
2. id(영어 소문자, 예: `fire_mage`)와 표시 이름을 적는다.
3. 복사해서 시작할 캐릭터를 고른다. 처음이면 테스트 파이터를 고른다.
4. 경기 그림 PNG를 고른다. 대기방 그림을 따로 고르지 않으면 경기 그림을 같이 쓴다.
5. **만들기**를 누른다. 캐릭터 파일, 대기방 선택칸 등록, 기획서(`GDD/characters/<id>.md`)가 자동으로 만들어진다.

## 수치 조절

| 탭 | 내용 |
|---|---|
| 기본 | 표시 이름, 몸 크기, 경기 그림 |
| 이동 | 이동 속도, 점프, 중력 등. 아래에 점프 높이와 복귀 거리가 계산되어 나온다 |
| 기술 | 가운데에서 고른 기술의 피해, 범위, 선딜·지속·후딜, 투사체 |
| 기믹 | 고유 기믹 선택과 그 수치 |

- 가운데 **기본 공격 / 스킬**과 **옆, 위·중립, 아래, 공중 위, 공중 아래**로 기술을 고른다. 미리보기에 파란 몸, 빨간 범위, 주황 발사 방향, 노란 투사체가 게임과 같은 비율로 나온다.
- 숫자 오른쪽의 "기준"은 테스트 파이터의 값이다. 다르면 노란색이 된다.
- "같은 기술을 쓰는 칸"이 보이면 그 칸들이 한 기술을 함께 쓰는 것이다. 한 칸만 바꾸려면 **이 칸만 따로 만들기**를 누른다.
- 왼쪽 **자동 검사**에 문제가 나오면 고친다.
- 바꾼 값은 **저장**을 눌러야 파일에 기록된다.
- 테스트 파이터는 비교 기준이라 수정할 수 없다.

## 투사체

기술 탭의 **투사체** 묶음에서 **추가**를 누르고, 발사 프레임과 각도를 정한 뒤 **만들기**로 투사체 수치를 만든다. **동작**에서 움직임을 고른다.

| 만들고 싶은 것 | 동작과 수치 |
|---|---|
| 직선 | 없음 |
| 포물선 | 기본 + 중력 |
| 점점 느려짐 | 기본 + 감속 |
| 설치물, 장판 | 기본 + 속도 0 + 긴 수명 |
| 빔 | 없음 + 긴 판정 크기 + 짧은 수명 |
| 유도 | 유도 |
| 부메랑 | 부메랑 |
| 몸에 붙어 휘두르기 | 몸에 붙어 휘두르기 |

## 연습실에서 사용감 맞추기

**연습실에서 테스트**를 누르면 저장한 뒤 이 캐릭터와 허수아비만 있는 연습실이 열린다.

| 키 | 동작 |
|---|---|
| A/D, Space, W/S, J, K | 게임과 같은 조작 |
| F1 | 조절 패널 켜기·끄기 |
| F2 | 판정 표시 켜기·끄기 |
| F3 | 슬로모션 (100% → 50% → 25%) |
| F4 | 처음 위치로 |

- 기술을 쓰면 오른쪽 패널에 그 기술의 수치가 나온다. 슬라이더를 움직이면 바로 적용된다.
- 파일에는 **저장**을 눌러야 기록된다. **되돌리기**는 마지막으로 저장한 값으로 돌아간다.
- **허수아비 배율**로 높은 배율에서 얼마나 날아가는지 볼 수 있다. **고정**을 켜면 맞아도 배율이 그대로다.
- 판정 표시의 파란 선은 몸, 빨강은 공격 범위, 노랑은 투사체다.

## 새로운 기믹이 필요할 때

변신, 콤보, 게이지처럼 수치만으로 안 되는 것은 AI에게 맡긴다.

1. 작업실 아래 **AI 요청문 복사**를 누른다.
2. AI에게 붙여 넣고 맨 아래에 원하는 기믹을 적는다.
3. 완성되면 **기믹** 탭 목록에 나타난다. 고르면 조절할 수치가 슬라이더로 나온다.
4. 만든 뒤에는 자동 검사(`tests/character_contract_test.gd`)를 AI에게 돌려 달라고 한다. 온라인에서 어긋나지 않는지 확인하는 검사다.

작업이 끝나면 바뀐 파일을 git으로 올린다. 세 명이 같은 때 새 캐릭터를 추가하면 `resources/content_catalog.tres`에서 충돌이 날 수 있다. 양쪽 줄을 모두 남기면 된다.
