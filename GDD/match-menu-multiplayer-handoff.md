# 경기 기본 규칙·메인 메뉴·멀티플레이어 구현 핸드오프

## 범위

메인 메뉴, 멀티플레이어 경기 진입 및 공유 경기 상태를 정의한다. 개발용 한 컴퓨터에서 둘 이상의 독립 클라이언트를 실행해 같은 경기에 접속하는 방식도 최소 구현 환경으로 허용한다.

## 확정 규칙

| 항목 | 규칙 |
|---|---|
| 최소 인원 | 경기 시작 전 참가 플레이어가 최소 2명이어야 한다. 2명 미만이면 시작할 수 없다. |
| 시작 위치 | 플레이어는 서로 다른 플랫폼 위 위치에서 시작한다. |
| 초기 스톡 | 각 플레이어는 스톡 3개로 시작한다. |
| 장외 및 스톡 | 장외 시 해당 플레이어의 스톡을 1개 차감한다. |
| 재참여 | 장외 후 스톡이 남으면 ??초 후 플랫폼에 닿아 있는 랜덤한 위치에서 재스폰한다. 스톡이 0개이면 현재 판에 재참여하지 않는다. |
| 재스폰 무적 | 재스폰 후 3초 동안 무적이며, 이 시간에는 외부 영향을 받지 않는다. |
| 승리 | 자신을 제외한 모든 플레이어의 스톡이 0개가 되면 승리한다. |

## 처리 흐름

### 메인 메뉴와 경기 진입

1. 게임 실행 시 메인 메뉴를 표시하고 멀티플레이어 경기 참여 흐름으로 진입할 수 있게 한다.
2. 경기 시작 전 참가 플레이어를 구별하고 인원수를 확인할 수 있는 대기 상태를 둔다.
3. 참가 인원이 2명 미만이면 경기 시작을 막고, 2명 이상이면 시작 가능한 상태로 둔다.

### 멀티플레이어 경기

1. 둘 이상의 플레이어가 각자 독립적인 입력과 상태로 같은 경기에 참여할 수 있게 한다.
2. 개발 단계에서는 한 컴퓨터의 여러 클라이언트를 각각 별도 플레이어로 접속시킬 수 있다. 각 클라이언트는 자신이 조작하는 플레이어를 구별한다.
3. 경기 시작 시 각 참가자에게 스톡 3개와 서로 다른 플랫폼 위 시작 위치를 배정한다.
4. 모든 참가자에게 참가 인원, 각 플레이어의 스톡, 경기 시작·종료 및 승리 결과를 일관되게 제공한다.
5. 장외 시 스톡을 차감한다. 스톡이 남으면 ??초 후 재스폰하고 3초 무적을 적용하며, 0개이면 현재 판에서 제외한다.
6. 한 플레이어를 제외한 나머지 모두의 스톡이 0개가 되면 해당 플레이어를 승자로 판정하고 결과를 표시한다.

## 확인 기준

- 메인 메뉴에서 멀티플레이어 경기 참여 흐름에 들어갈 수 있다.
- 독립 클라이언트 둘 이상 또는 동등한 구성으로 같은 경기에 참가할 수 있다.
- 참가자가 1명이면 시작할 수 없고, 2명 이상이면 시작 가능한 상태가 된다.
- 참가자는 서로 다른 플랫폼 위 위치에서 스톡 3개로 시작한다.
- 각 클라이언트는 자신에게 배정된 플레이어만 조작한다.
- 장외 한 번에 해당 플레이어의 스톡이 1개 차감되고, 스톡 0개인 플레이어는 재참여하지 않는다.
- 한 플레이어를 제외한 모두의 스톡이 0개이면 그 플레이어가 승자로 표시된다.

## [검토]

- 다른 컴퓨터 간 접속 지원 여부는 미정이다.
- 방 생성·참가 방식, 경기 시작 권한·입력 및 대기 화면 구성은 미정이다.
- 최대 플레이어 수와 경기 중 입장·퇴장·재접속 처리는 미정이다.
- 재경기 시 스톡 초기화 방식은 미정이다.
- 동시 탈락, 연결 종료 및 무승부가 가능한 경우의 결과는 미정이다.
- 시작 위치의 좌표·개수·배정 순서·무작위 여부와 중복 방지 기준은 미정이다.
- 재스폰까지의 대기 시간은 ??초이며, 랜덤 위치 선정 기준은 미정이다.
- 무적 중 차단할 ‘외부 영향’의 구체적인 범위는 미정이다.
- 메뉴·대기·결과 화면의 문구·구성·오류 안내·승리 표시 방식은 미정이다.
- 경기 상태를 확정하는 주체와 동기화 방식은 미정이다.
