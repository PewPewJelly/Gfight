# 장외 및 패배 규칙 개발 Handoff

## 1. 구현 목표

플레이어의 피격 누적에 따라 넉백을 강화하고, 장외 판정과 스톡 차감 및 재참여를 처리한다.

## 2. 넉백 배율

- 각 플레이어는 개별적으로 `넉백 배율` 값을 가진다.
    
- 게임 시작 시 넉백 배율을 `0%`로 설정한다.
    
- 플레이어가 공격에 적중하여 피해를 받을 때마다 해당 플레이어의 넉백 배율을 증가시킨다.
    
- 증가량은 적중한 공격에 따라 다르게 적용한다.
    
- 넉백은 공격이 가해진 방향을 기준으로 적용한다.
    
- 누적된 넉백 배율이 높을수록 피격 시 날아가는 거리가 증가해야 한다.
    
- 스톡이 `1` 차감되면 해당 플레이어의 넉백 배율을 즉시 `0%`로 초기화한다.
    

## 3. 장외 및 스톡 처리

- 각 플레이어는 게임 시작 시 스톡 `3개`를 가진다.
    
- 플레이어가 화면 밖으로 기준 거리 `??` 이상 벗어나면 장외로 판정한다.
    
- 장외 판정 시 해당 플레이어의 스톡을 `1` 차감한다.
    
- 남은 스톡이 있으면 해당 판에 다시 참여할 수 있도록 처리한다.
    
- 남은 스톡이 없으면 해당 플레이어는 현재 판에 다시 참여할 수 없다.
    
- 스톡이 없는 플레이어에게는 재참여 처리가 실행되지 않아야 한다.
    

## 4. 처리 순서

피격이 발생하면 다음 순서로 처리한다.

1. 적중한 공격을 식별한다.
    
2. 공격 방향을 산출한다.
    
3. 피해를 적용한다.
    
4. 공격별 증가량에 따라 피격자의 넉백 배율을 `??%` 증가시킨다.
    
5. 현재 넉백 배율을 반영하여 공격 방향으로 넉백시킨다.
    

장외가 발생하면 다음 순서로 처리한다.

1. 플레이어가 화면 밖 기준 거리 `??`를 넘었는지 확인한다.
    
2. 장외로 판정된 플레이어의 스톡을 `1` 차감한다.
    
3. 해당 플레이어의 넉백 배율을 `0%`로 초기화한다.
    
4. 남은 스톡을 확인한다.
    
5. 스톡이 남아 있으면 재참여 처리한다.
    
6. 스톡이 없으면 현재 판에서 제외한다.
    

## 5. 완료 조건

- 게임 시작 시 모든 플레이어의 넉백 배율이 `0%`이고 스톡이 `3개`다.
    
- 피해를 받을 때 피격자의 넉백 배율이 해당 공격에 설정된 값만큼 증가한다.
    
- 넉백 배율이 증가할수록 동일 조건의 공격에 의해 날아가는 거리가 증가한다.
    
- 넉백 방향이 공격 방향과 일치한다.
    
- 화면 밖 기준 거리 `??`를 넘으면 스톡이 정확히 `1` 차감된다.
    
- 스톡 차감과 함께 넉백 배율이 `0%`로 초기화된다.
    
- 스톡이 남은 플레이어는 재참여할 수 있다.
    
- 마지막 스톡을 잃은 플레이어는 해당 판에 재참여하지 않는다.
    
- 하나의 장외 사건으로 스톡이 중복 차감되지 않는다.
    

## 검토

메모와 참고사항만으로 확정할 수 없어 별도 결정이 필요한 항목이다.

- 공격별 넉백 배율 증가량 `??%`
    
- 넉백 배율을 실제 넉백 거리 또는 힘에 반영하는 계산식
    
- 넉백 배율의 최댓값 또는 상한 적용 여부
    
- 피해량과 넉백 배율 증가량의 관계
    
- 공격 방향을 판정하는 기준
    
- 화면 밖 장외 판정의 기준점과 거리 `??`
    
- 장외 판정 영역의 상·하·좌·우 적용 범위
    
- 재참여 위치와 재참여까지의 대기 시간 `??`
    
- 재참여 직후 무적 시간 `??` 및 무적 적용 여부
    
- 장외 시 진행 중인 이동·공격·피격 상태의 초기화 범위
    
- 스톡이 없는 플레이어의 오브젝트를 제거할지, 비활성화할지 여부
    
- 모든 상대가 스톡을 잃었을 때 승패를 확정하는 방식
    
- 자해, 환경 요소 또는 공격 주체가 없는 넉백의 방향 처리 방식
    
- 동시에 여러 공격을 맞았을 때 넉백 방향과 배율 증가를 처리하는 방식
