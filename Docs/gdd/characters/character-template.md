# 캐릭터 기획서 양식

> 새 캐릭터는 Godot의 **캐릭터 작업실** 탭에서 만들면 이 양식이 `Docs/gdd/characters/<id>.md`로 자동 복사된다([`workshop-guide.md`](workshop-guide.md)). 작성 예시는 [`test_fighter.md`](test_fighter.md).
>
> - 표기: 아직 정하지 않은 값은 `??`, 논의가 필요한 항목은 `[검토]`, 기획이 제안하는 기본값은 `[제안]`(Docs/00 §2.1-6). 개발은 `??`·`[검토]`를 확정하지 않고 임시값으로 구현한 뒤 `Docs/gdd/implementation-status.md`에 적는다.
> - 단위: 거리·크기 px, 속도 px/s, 가속도 px/s², 시간 초, 배율 %. 방향은 Godot 좌표(오른쪽 +x, **아래 +y**).
> - "기본값"은 테스트 파이터(현재 유일한 캐릭터)의 값이다. 기본값과 같으면 "이 캐릭터" 칸에 `=`만 적는다.

## 6. 기술 슬롯과 입력 (기본 공격·스킬 공통)

기본 공격과 스킬은 같은 슬롯 5개를 쓴다. 중립(방향 없음)과 위는 같은 기술이 나가고, 공중에서는 위·아래를 따로 둔다. 옆은 땅·공중이 같다.

슬롯 이름의 위·아래·옆은 **누르는 방향**이다. 위 기술이라고 위를 칠 필요는 없다. 범위 위치와 발사 방향은 기술마다 정한다.

조작: `A`/`D` 좌우 이동, `W` 위 방향(점프 아님), `S` 아래 방향(혼자 누르면 플랫폼 아래로 내려감), `Space` 점프(임시), `J` 기본 공격, `K` 스킬(임시).

| 슬롯 | 뜻 |
|---|---|
| 옆 | 땅·공중 공통 |
| 위·중립 | 땅에서 방향 없이, 또는 위로 |
| 아래 | 땅에서 아래로 |
| 공중 위 | 공중에서 방향 없이, 또는 위로 |
| 공중 아래 | 공중에서 아래로 |

입력 해석 ("버튼" = 기본 공격 `J` 또는 스킬 키):

| 상태 | 입력 | 슬롯 | 비고 |
|---|---|---|---|
| 땅 | 버튼만, `W` + 버튼 | 위·중립 | 둘은 같은 기술 |
| 땅 | `A`/`D` + 버튼 | 옆 | 누른 쪽을 보고 나간다 |
| 땅 | `S` + 버튼 | 아래 | 플랫폼 아래로 내려가지 않는다 |
| 공중 | 버튼만, `W` + 버튼 | 공중 위 | 둘은 같은 기술 |
| 공중 | `A`/`D` + 버튼 | 옆 | 땅의 옆과 같은 기술 |
| 공중 | `S` + 버튼 | 공중 아래 | |

- 방향을 여러 개 누르면 위 > 아래 > 옆 순서로 고른다 (현재 규칙 유지).
- 점프 키와 버튼을 같은 순간에 누르면 점프가 먼저 나가 공중 기술이 된다.
- 공중 위·공중 아래 칸이 비어 있으면 땅의 위·중립, 아래 기술을 쓴다.
- 코드는 이 체계로 구현되어 있다(`CharacterDef.Slot`, `Fighter.move_slot`).
- 슬롯 체계는 5칸으로 확정했다(2026-11-09). J+K 동시 입력 같은 특수 입력은 슬롯을 늘리지 않고 캐릭터 고유 스크립트에서 처리한다(`Docs/gdd/characters/kit-rules.md`).

## 7. 기본 공격 (`AttackData`)

공통 규칙 (`Docs/gdd/attack-handoff.md`, `Docs/gdd/implementation-status.md` §공격):

- 판정: 7.4의 선딜 뒤 지속 프레임 동안 사각형 범위로 판정한다. 기본값은 시작 프레임 1회 판정이다. 공격 1회당 상대마다 한 번만 맞는다.
- 발사 속도 = 기본 발사 속도 × (1 + 맞은 뒤 배율 ÷ 100). 예: 배율 0%인 상대가 배율 증가 12%인 공격에 맞으면 발사 속도 × 1.12.
- 피해는 기록용이다. HP나 피해에 따른 탈락은 없고, 날아가는 거리는 배율로만 정해진다.

### 7.1 항목 뜻

| 항목 | 필드 | 뜻 |
|---|---|---|
| 피해 | `damage` | 누적 피해 기록 |
| 배율 증가 | `percent_increase` | 맞은 상대의 넉백 배율이 오르는 양 (%) |
| 기본 발사 속도 | `base_launch_speed` | 배율 0%일 때 상대가 날아가는 속도 |
| 피격 경직 | `hitstun_seconds` | 맞은 상대가 이동·점프·공격을 못 하는 시간 |
| 범위 길이 | `reach` | 몸 가장자리에서 공격 방향으로 뻗는 길이 |
| 범위 폭 | `width` | 공격 방향과 수직인 두께 |
| 범위 위치 | `anchor` | 몸 앞(`FRONT`) / 머리 위(`ABOVE`) / 발밑(`BELOW`). 그 밖의 위치(몸 둘레, 대각선 등)는 신규 |
| 발사 방향 | `launch_direction` | 오른쪽을 볼 때 기준 (x, y). 왼쪽을 보면 x가 뒤집힌다. 위로 띄우려면 y를 음수로 |

### 7.4 공격 타이밍 (선택)

기본 공격과 스킬 공통이다. 프레임은 1/60초다. 기본값 그대로면 누른 프레임에 바로 판정하고 끝난다.

| 항목 | 필드 | 기본값 | 이 캐릭터 | 반영 |
|---|---|---|---|---|
| 선딜 | `startup_frames` | 0 | | 적용 |
| 지속 | `active_frames` | 1 | | 적용 |
| 후딜 | `recovery_frames` | 0 | | 적용 |
| 다음 기술까지 대기 | `cooldown_override` (초) | -1 (5장의 공격 재사용 대기를 쓴다) | | 적용 |
| 사용 중 이동 | `move_lock` | 자유(`FREE`). `ROOTED`면 기술이 끝날 때까지 걷기·점프 불가 | | 적용 |
| 사용 중 그림 | `pose` | 없음 (경기 중 그림 유지) | | 적용 |

- 기술이 진행되는 동안에는 다른 기술을 시작할 수 없고 바라보는 방향도 고정된다.
- 맞으면 진행 중인 기술은 취소된다.

## 8. 스킬

스킬은 `SkillData` 리소스다(기본 공격 값 + 재사용 대기 + 자기 이동). 8.3 표의 "반영" 열을 확인한다.

### 8.1 스킬 공통 규칙

| 항목 | 내용 |
|---|---|
| 스킬 키 | `K` (임시) [검토] |
| 방향·땅/공중 | 6장 슬롯 규칙을 그대로 쓴다 |
| 넉백 중 사용 | 불가 (기본 공격과 같음) |
| 재사용 대기 | 스킬마다 따로. 스킬을 쓰면 기본 공격 재사용 대기도 함께 걸린다. 같은 프레임에 J와 K를 누르면 기본 공격이 우선 (임시) |
| 복귀 | 스킬로 캐릭터가 이동하면(특히 위로) 2단 점프 기준 장외 라인과 맞지 않게 된다. 장외 라인 계산에 아직 넣지 않는다 [검토] |

### 8.2 스킬 목록

공중 위·공중 아래가 땅의 기술과 같으면 이름 칸에 `= 위·중립`, `= 아래`라고만 적는다. 다른 기술일 때만 8.3 상세를 따로 쓴다.

| 슬롯 | 입력 | 이름 | 종류 | 한 줄 설명 |
|---|---|---|---|---|
| 옆 | `A`/`D` + 스킬 | | | |
| 위·중립 | 땅에서 스킬, `W` + 스킬 | | | |

### 8.5 투사체 (투사체마다 이 표를 복사)

투사체는 세 부분으로 나뉜다. 어떤 기술이 언제 쏘는지(트리거), 수치(`ProjectileData`), 어떻게 움직이는지(동작 스크립트).

몸에서 떨어져 판정이 움직이거나 남아 있는 것은 전부 투사체로 만든다. 설치물, 장판, 빔, 몸에 붙어 휘두르는 판정도 포함이다.
