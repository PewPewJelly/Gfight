# 기본 규칙 개발 핸드오프

## 범위

경기 참가, 시작, 장외, 재스폰, 무적 및 승리의 기본 규칙을 정의한다.

## 확정 규칙

| 항목 | 규칙 |
|---|---|
| 최소 인원 | 경기 시작 전 참가 플레이어가 최소 2명이어야 한다. 2명 미만이면 시작할 수 없다. |
| 시작 스톡 | 각 플레이어는 스톡 3개로 시작한다. |
| 시작 위치 | 플레이어들은 서로 다른 위치에서 플랫폼 위에 서 있는 상태로 시작한다. |
| 카메라 | 플랫폼 전체가 한눈에 보이도록 설정한다. |
| 장외 | 장외된 플레이어의 스톡을 1개 차감한다. |
| 재스폰 | 장외 후 스톡이 남은 플레이어만 ??초 후 플랫폼에 닿아 있는 랜덤한 위치에서 재스폰한다. |
| 스톡 소진 | 스톡이 0개가 된 플레이어는 현재 판에 재참여하지 않는다. |
| 재스폰 무적 | 재스폰된 플레이어는 3초 동안 무적이며, 이 시간에는 외부 영향을 받지 않는다. |
| 승리 | 자신을 제외한 모든 플레이어의 스톡이 0개가 되면 승리한다. |

## 처리 흐름

1. 경기 시작 전 참가 인원을 확인하고, 2명 이상일 때만 경기를 시작한다.
2. 각 플레이어에게 스톡 3개와 서로 다른 플랫폼 위 시작 위치를 배정한다.
3. 장외 판정이 발생하면 해당 플레이어의 스톡을 1개 차감한다.
4. 스톡이 남아 있으면 ??초 후 플랫폼에 닿아 있는 랜덤한 위치에 재스폰하고 3초 무적을 적용한다.
5. 스톡이 0개이면 현재 판에서 제외한다. 한 플레이어를 제외한 모든 플레이어의 스톡이 0개가 되면 승리 처리한다.

## 확인 기준

- 참가자가 2명 미만이면 경기를 시작할 수 없다.
- 모든 플레이어는 스톡 3개와 서로 다른 플랫폼 위 위치에서 시작한다.
- 장외 한 번에 스톡이 1개 차감된다.
- 스톡이 남은 플레이어만 재스폰하며, 재스폰 후 3초간 무적이다.
- 스톡이 0개가 된 플레이어는 해당 판에 재참여하지 않는다.
- 한 플레이어를 제외한 모두의 스톡이 0개이면 그 플레이어가 승리한다.
