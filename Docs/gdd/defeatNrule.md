# 장외 및 패배 규칙 개발 핸드오프

## 범위

피격에 따른 넉백 배율, 장외 판정, 스톡 차감 및 재참여를 처리한다.

## 확정 규칙

| 항목 | 규칙 |
|---|---|
| 넉백 배율 | 각 플레이어가 개별적으로 관리하며, 게임 시작 시 0%다. |
| 피격 | 공격에 적중해 피해를 받을 때마다 피격자의 넉백 배율을 공격별 증가량 ??%만큼 누적한다. |
| 넉백 방향 | 공격이 가해진 방향을 기준으로 적용한다. |
| 넉백 거리 | 누적 배율이 높을수록 동일 조건의 피격에서 더 멀리 날아간다. |
| 초기 스톡 | 각 플레이어는 3개로 시작한다. |
| 장외 | 화면 밖 기준 거리 ?? 이상 벗어나면 장외로 판정하고 스톡을 1개 차감한다. |
| 배율 초기화 | 스톡이 1개 차감되면 해당 플레이어의 넉백 배율을 즉시 0%로 초기화한다. |
| 재참여 | 스톡이 남아 있으면 ??초 후 플랫폼에 닿아 있는 랜덤한 위치에서 재스폰한다. 스톡이 0개이면 현재 판에서 제외한다. |
| 재스폰 무적 | 재스폰된 플레이어는 3초 동안 무적이며, 이 시간에는 외부 영향을 받지 않는다. |
| 승리 | 자신을 제외한 모든 플레이어의 스톡이 0개가 되면 승리한다. |

## 처리 흐름

### 피격

1. 적중한 공격을 식별하고 공격 방향을 산출한다.
2. 피해를 적용하고, 피격자의 넉백 배율을 해당 공격의 증가량 ??%만큼 올린다.
3. 증가한 현재 배율을 반영해 공격 방향으로 넉백시킨다.

### 장외

1. 플레이어가 화면 밖 기준 거리 ??를 넘었는지 확인한다.
2. 하나의 장외 사건에 대해 스톡을 1개 차감하고 넉백 배율을 즉시 0%로 초기화한다.
3. 스톡이 남아 있으면 ??초 후 재스폰하고 3초 무적을 적용한다.
4. 스톡이 0개이면 현재 판에서 제외하고 재참여시키지 않는다.
5. 한 플레이어를 제외한 모두의 스톡이 0개이면 승리를 처리한다.

## 확인 기준

- 시작 시 모든 플레이어의 넉백 배율은 0%, 스톡은 3개다.
- 피격자의 배율이 적중한 공격에 설정된 값만큼 증가하고, 높은 배율에서 넉백 거리가 더 길어진다.
- 넉백 방향은 공격 방향과 일치한다.
- 장외 한 번에 스톡이 정확히 1개 차감되고 배율이 0%로 초기화된다.
- 스톡이 남은 플레이어만 재스폰하며, 재스폰 후 3초간 무적이다.
- 마지막 스톡을 잃은 플레이어는 해당 판에 재참여하지 않는다.
- 하나의 장외 사건으로 스톡이 중복 차감되지 않는다.
