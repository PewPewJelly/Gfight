## 1. 공통 규칙

### 1.1 시각 체계 [결정 1·2·8]

**색.** 메인 메뉴가 쓰는 값만 씁니다. 화면마다 따로 정한 색(대기방 `LOBBY_*`, HUD·결과의 남색 #101927, 온라인 화면의 분홍 카드와 하드코딩 색 14개)은 모두 아래로 바꿉니다.

| 용도 | 값 | 지금 상수 |
|---|---|---|
| 글자·판(검정) | #141416 | `UiStyle.MAIN_INK` |
| 강조·선택(노랑) | #eba823 | `UiStyle.MAIN_YELLOW` |
| 노랑 위 보조 글자(갈색) | #3a2a08 | `UiStyle.MAIN_BROWN` |
| 선택된 글자 | #ffffff | `UiStyle.MAIN_SELECTED_TEXT` |
| 종이(밝은 판) | #fff4d6 | `UiStyle.MAIN_PAPER` |
| 배경 | 그라데이션 #E39A16 → #F2BC45 → #FCE6AE | 메인 메뉴 배경 |

- [제안] 오류 표시는 새 색을 만들지 않고 **검정 판 + 흰 글자 + "!" 표시**로 합니다. 빨강 글자는 노란 배경에서 잘 안 읽힙니다.
- [제안] 슬롯 색(빨강 e05555 · 파랑 4f7cff · 초록 3aa865 · 노랑 e3b23c)은 **검정 또는 흰 판 위에만** 놓습니다. 노랑 슬롯 색은 노란 배경 위에서 보이지 않습니다.

**글꼴.** 영어·숫자는 Barlow Condensed, 한글은 Noto Sans KR. 파일은 `resources/fonts/files/`에 있습니다. 대기방·HUD·결과 화면이 쓰는 Godot 기본 글꼴은 없앱니다.

**기울기.** 9°. 대기방의 12°(`LobbyGeometry.SKEW_DEG`)를 9°로 맞춥니다.

**장식.** 메인 메뉴 장식(`assets/main_menu/`의 `edge_strip.svg` 찢어진 종이 가장자리, `grain.svg` 점 질감, `selected_wedge.svg` 선택 쐐기, 검정 띠)을 다른 화면에서도 씁니다. 도형과 글자 위주 원칙은 그대로입니다.

**구현.** [제안] 색·글꼴·버튼 모양을 프로젝트 Theme 하나로 만들고 `project.godot`의 `gui/theme/custom`에 지정합니다(지금은 비어 있음). 새 화면이 자동으로 같은 모양을 갖습니다.

**배경 [결정 8].** 온라인 화면의 보노보노 사진(480×300을 4배 확대)을 뺍니다. [제안] 대신 메인 메뉴 그라데이션 + `grain.svg`를 씁니다. 사진 파일 삭제 여부는 교체 작업 때 정합니다.

**애니메이션 [결정 2].** 대기방은 금지를 유지합니다(버튼 누를 때 3px 눌림만 허용). [제안] 다른 화면은 메인 메뉴 수준까지 허용합니다(§4-3에서 확정 필요).

### 1.2 조작 [결정 3]

키보드만으로 메인 메뉴부터 결과 화면까지 끝낼 수 있어야 합니다. 마우스는 보조로 남깁니다.

| 동작 | 키 | 비고 |
|---|---|---|
| 항목 이동 | 방향키 | [제안] W/A/S/D도 함께. 경기 조작(A/D 이동, J 공격)과 손 위치가 같아집니다 |
| 확인 | J · Enter | 글자 입력 칸 안에서는 Enter만 (J는 글자로 들어감) |
| 뒤로 · 창 닫기 | Esc | |
| 대기방 채팅 열기 | T | 채팅 칸에서 Enter 보내기, Esc 닫기. 지금의 Enter 열기(`lobby_screen.gd` 225행)를 바꿉니다 |
| 대기방 탭 전환 | Q / E | [제안] |

- [제안] 모든 화면 오른쪽 아래에 메인 메뉴 모양의 키 안내를 둡니다. 글자는 한글로: `J·Enter 확인` · `Esc 뒤로`.
- [제안] 화면에 들어가면 항상 한 항목이 선택된 상태로 시작하고, 선택은 노란 쐐기로 보입니다.
- 게임패드는 이번 범위가 아닙니다.

### 1.3 플레이어 표기 [결정 5]

모든 곳에서 **`닉네임 · P번호`** 형식과 **슬롯 색 띠**를 함께 씁니다. 닉네임이 같아도 P번호로 구분됩니다.

| 위치 | 표기 예 |
|---|---|
| 대기방 카드 | 민수 · P2 (8px 슬롯 색 띠) |
| 경기 HUD 카드 | 민수 · P2 |
| 머리 위 표시 | [제안] 내 캐릭터 `▼나`, 다른 캐릭터 `▼민수` |
| 결과 제목 | 민수 승리! (지금은 "P2 승리!") |
| 결과 열 머리 | 민수 · P2 |
| 입장·퇴장 알림 | 민수 님이 들어왔습니다. / 민수 님이 나갔습니다. |

- [제안] 칸보다 긴 닉네임은 끝을 "…"로 줄입니다.

### 1.4 읽기 쉬움 [제안]

- 색만으로 구분하지 않습니다. 슬롯 색에는 항상 P번호 글자를 붙입니다(빨강·초록은 색각 이상이 있으면 구분이 어렵습니다).
- 최소 글자 크기: 1080p 화면 기준 24px, 1280×720 캔버스 기준 16px.

### 1.5 용어 [제안]

| 쓰는 말 | 쓰지 않는 말 | 바꿀 곳 |
|---|---|---|
| 방장 | 호스트 | `UiStyle.HOST_LOST`, `UiStyle.ROOM_CLOSED` |
| 방 만들기 | 방 생성 | `UiStyle.CREATE_ROOM` |
| 경기 시작 | 게임 시작 | `UiStyle.TIP_START` |
| 대기방 | 로비 | 화면 글자 |
| 올린 배율 | 준 배율 | `UiStyle.DEALT` |
| 키 안내 `Esc 뒤로` | "← 뒤로" 글자 버튼 | `online_screen.tscn` 82행 |

그 밖에 고정 용어: 준비 / 준비 해제, 나가기, 장외 / 재등장 / 탈락, 확인 / 취소.

## 2. 화면별

### 2.1 S1 메인 메뉴 · PLAY 하위 메뉴

- **[결정 7] 종료 확인 창.** Esc를 누르면 바로 끄지 않고(지금 `main_menu_screen.gd` 167행 `get_tree().quit()`) 창을 띄웁니다.
  - 제목 "게임을 종료할까요?", 버튼 [종료] [취소].
  - 처음 선택은 [취소]. Esc는 [취소]와 같습니다. J·Enter는 선택한 버튼을 누릅니다.
  - 모양은 메인 메뉴 그대로(검정 판, 노란 선택 쐐기, 9° 기울기).
- [제안] GUIDEBOOK·SETTINGS를 확인하면 "준비 중입니다."를 1.5초 보여 줍니다.
- [제안] 키 안내 글자를 한글로 바꿉니다(지금 `Confirm` · `Close` · `Back`).
- [제안] 시작 연출은 아무 키로 건너뜁니다.
- [제안] 왼쪽 아래에 버전(예: v0.1.0)을 표시합니다.

### 2.2 온라인 공개 방 화면 (옛 S1-1 IP 입력 창을 대체)

- **[결정 4]** 참가는 공개 방 목록에서만 합니다. 코드 입력 칸, 비공개·친구 전용 옵션은 만들지 않습니다.
- **[결정 1·8]** 보노보노 배경과 분홍 카드를 메인 메뉴 스타일(배경 그라데이션, 검정·흰 판)로 바꿉니다.
- **방 카드 내용:** 방 이름 · 방장 닉네임 · 인원 `n/4`와 점 4개 · 상태(대기 중 / 경기 중 / 가득 참). 맵·규칙은 실제 값이 있을 때만 표시합니다.
- [제안] 경기 중·가득 참인 방은 목록 아래쪽에 흐리게 두고 선택되지 않게 합니다. 그 사이에 상태가 바뀌는 경우를 위해 "방이 가득 찼습니다.", "이미 경기가 진행 중입니다." 문구는 남깁니다.
- **목록 상태 3가지:**
  - 불러오는 중
  - 빈 목록: "열린 방이 없습니다. 방을 만들어 친구를 불러 보세요."
  - 실패: "공개 방 목록을 불러오지 못했습니다." + [다시 시도]
- [제안] 3초마다 새로 고치되, 카드는 방 id로 유지하고 만든 순서를 고정해 자리가 튀지 않게 합니다. 선택도 유지합니다.
- [제안] 오류는 토스트만 띄우지 말고 관련 칸·카드 바로 옆에도 표시합니다. 지금 문구를 그대로 씁니다: "방 이름을 입력해 주세요.", "방을 만들지 못했습니다. 잠시 후 다시 시도해 주세요.", "방 연결을 시작하지 못했습니다.", "상대와의 P2P 연결에 실패했습니다. 다시 시도해 주세요."
- [제안] 연결 중에는 남은 초(P2P 연결 제한 15초)와 [취소](Esc)를 보여 줍니다.
- [제안] 플레이어에게 보이는 "방에 연결되었습니다. F3에서 연결 상태를 볼 수 있습니다."(`online_screen.gd` 183행)에서 F3 안내를 뺍니다. F3 연결 상태 창 자체는 개발용으로 둡니다.

### 2.3 S2 대기방

- **[결정 1·2]** 회색 `LOBBY_*` 색을 메인 메뉴 색으로, 기울기 12°를 9°로, 기본 글꼴을 Barlow·Noto로 바꿉니다. 애니메이션 금지는 유지합니다(3px 눌림만).
- **[결정 4] 지울 것:** 방 주소 팝오버, 방 이름 옆 ⓘ 버튼, [복사] 버튼, 빈 자리 안내 "ⓘ 버튼으로 방 주소를 공유해 보세요"(`UiStyle.INVITE_HINT`, `player_list.gd` 181행).
  - [제안] 빈 자리 안내 대체 문구: "공개 방 목록에서 들어올 수 있습니다."
- **[결정 5] 카드:** 닉네임을 크게, `P2`를 작게, 왼쪽에 8px 슬롯 색 띠. [제안] 방장은 아이콘만 쓰지 말고 "방장" 글자를 붙입니다.
- **[결정 3] 키:** J·Enter 준비 / 준비 해제(방장은 경기 시작), T 채팅, Esc 나가기(확인 창).
- [제안] 모두 준비되면 움직이지 않는 띠를 보여 줍니다. 방장 화면 "모두 준비 완료 · J·Enter로 시작", 다른 사람 화면 "방장이 시작하기를 기다리는 중".
- [제안] 버튼에는 항상 글자("준비" / "준비 해제" / "경기 시작")를 씁니다.

### 2.4 S3 경기 HUD

- **[결정 1]** 남색 카드를 검정 판 카드로, 숫자는 Barlow로 바꿉니다. 내 카드는 노란 테두리.
- **[결정 5]** 카드 제목 `민수 · P1`.
- [제안] 화면 아래 띠 배경(높이 130px, 불투명도 92%)을 없앱니다. 띠가 y 590부터 덮어서 무대 아래 복귀 구간이 가려집니다(본 무대 y 540~570, 아래 장외선 약 y 796). 카드만 남기고 불투명도 60%, 캐릭터가 카드 뒤에 있으면 30%.
- [제안] 맞으면 배율 숫자가 0.15초 동안 1.2배로 커지고 2px 흔들립니다.
- [제안] 장외되면 해당 카드가 한 번 번쩍입니다.
- [제안] 1280×720 캔버스 기준 카드 제목 16 → 18, `▼나` 18 → 22.
- 배율 위험 색(0% 흰색 → 100% 주황 → 200% 빨강)과 화면 가운데 재등장 카운트다운 상자는 그대로 둡니다.

### 2.5 S4 결과

- **[결정 6]** 확인 안 한 사람이 1명만 남으면 그 사람 열에 "15초 뒤 자동 확인" 카운트다운을 띄우고, 0이 되면 자동 확인합니다. 2명 이상 남았으면 지금처럼 기다립니다. [제안] 그 1명이 나가면 확인한 것으로 봅니다.
- **[결정 5]** 제목 "민수 승리!", 열 머리 `민수 · P2`.
- **[결정 1]** 남색 배경을 메인 메뉴 스타일로 바꿉니다.
- [제안] 지금은 1등과 "나"가 둘 다 3px 테두리라 겹치고, 강조색 #4f7cff가 P2 파랑과 같습니다. 1등 열은 24px 올리고 1등 슬롯 색을 15% 깔며, 내 열은 "(나)" 글자로만 표시합니다.

- [제안] "준 배율"을 "올린 배율"로 바꿉니다.
- 표시 항목은 처치 수와 올린 배율만(ui-ux-scenes-v2.pdf 기준) 그대로 둡니다.

## 4. 결정 필요

1. **결정 9 보류 동안 기준 문서.** 옛 문서와 이 문서가 다르면 어느 쪽을 따를지 정해야 합니다. 제안: 이 문서의 [결정] 항목이 우선이고, [제안] 항목은 승인 전까지 옛 문서를 따릅니다.
2. **방장이 나갈 때 실제 동작.** 공개 방(클라우드)에서 [나가기]는 내 연결만 끊습니다(`session.gd` 559행 `leave_room()`). 방장을 넘기는 일은 서버(Cloudflare)가 하는데 서버 코드가 이 저장소에 없어 확인하지 못했습니다. 2명 접속 시험으로 확인한 뒤, 넘어가면 확인 문구를 "나가면 다른 사람에게 방장이 넘어갑니다."로 바꿉니다(지금 문구는 `UiStyle.CLOSE_ROOM_CONFIRM`, 표시는 `lobby_screen.gd` 688행).
3. **대기방 밖 애니메이션 범위.** 제안: 메인 메뉴 수준까지(한 번에 0.3초 이하의 짧은 이동·번쩍임, 반복 움직임 없음).
4. **[제안] 항목 승인 방식.** 한꺼번에 승인할지, 화면을 만들 때마다 하나씩 볼지.
